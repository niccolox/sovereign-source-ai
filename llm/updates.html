sovsrc.llm updates

sovsrc.llm is a specification for an LLM that uses source material with permission, gives credit to the people who made it, and plans rewards for creators.

The project is at specification stage. No application, trained model, or payment system exists. This page gets a new entry for each commit to the repository. A machine writes the summaries from the change, so read the source before you quote a summary.
