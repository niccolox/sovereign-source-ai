Hermes Agent research proposes an optional interface for Sovereign Source

New research proposes evaluating a self-hosted Hermes Agent interface for permission and attribution services. The proposed integration has no implementation or benchmarks.

11 Oct 2026 · commit c6717de

Proposed integration

The research proposes a selected model and a small set of Super Intellectual Property tools. The proposed architecture assigns rights decisions, contribution records and reward accounting to Rust/Axum and PostgreSQL.

docs/HERMES_AGENT_RESEARCH.md

Permission boundaries

The research separates agent software licensing from model, provider and content permissions. It proposes checking provenance and permissions for each intended training use before admitting exported conversations.

docs/HERMES_AGENT_RESEARCH.md

Model routing and costs

The research proposes checking primary, auxiliary, delegated and fallback model requests. It proposes separate budgets for hosting, inference, external services, storage and maintenance, with costs dependent on model choice and measured workload.

Access and documentation
