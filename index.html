What we build

We do the full build for you, in accounts that you control. We build three parts. Each part is useful alone. The details for small businesses

  1. A data warehouse that you own We put your business data in one place, in your own cloud account. It uses an open-source database, such as Postgres.
  2. Connectors for your SaaS tools Connectors pull data from the tools that you use now. They find the same customer, product, or job in each tool and match the records.
  3. AI agents for your industry Agents draft, check, and flag work from that data. They use only the data and tools that you allow. They record each action, and a person approves the result.

Why we build it this way

A model on your own server can still lock you in. The lock can come from APIs, identity, proprietary data, or prompts that nobody documented. It can also come from agent runtimes, workflow engines, cloud infrastructure, or one provider that you cannot replace. An open-weight model on your server does not make you sovereign. A self-hosted application does not make you sovereign. Sovereignty is a property of the full system.

What sovereign means

Seven questions show if a system is sovereign. Ask them of any vendor, and ask them of us.

  1. Can you replace the main vendor without a rebuild of the institution?
  2. Can you move the runtime to another environment?
  3. Can the organization keep its data and knowledge, and build them again?
  4. Can you inspect the permissions and actions of each agent?
  5. Can you change models and keep the same business logic?
  6. Can critical functions run privately or in restricted networks?
  7. Does the organization keep control of identity, keys, policy, authorization, provenance, and audit?

The architecture

Sovereign Source AI has seven layers that support each other.

  1. 01 Intent What a person or institution wants to do. It is a typed object that links to requirements, constraints, authority, and outcomes that you can measure.
  2. 02 Governance Authority, policy, data classification, jurisdiction, model and tool permissions, network access, and approvals. Authorization is outside the model. A model can propose an action. It cannot give itself permission.
  3. 03 Decision Deterministic rules, bounded models, statistical inference, LLMs that reason, and human judgment.
  4. 04 Capability You declare each operation and its permissions. The system makes them available as Sovereign Skills and MCP-style interfaces.
  5. 05 Execution Isolated agents, workers, workflows, services, and infrastructure.
  6. 06 Verification Tests, evaluations, policy checks, security analysis, simulation, approvals, and measurement of outcomes. These checks change claims into evidence.
  7. 07 Evidence Durable provenance records that link intent to decisions, actions, artifacts, releases, and outcomes.

Intent → Decide → Constrain → Execute → Verify → Prove

Models reason. Policies authorize. Capabilities constrain. Execution acts. Audit proves.

No artifact without intent. No agent without policy. No execution without isolation. No dependency without provenance. No release without evidence.

What it is not

Not a model
It works with any LLM, any cloud, and any vendor, and you can replace each vendor. Palantir, Payload, PostHog, MCP servers, open models, proprietary frontier models, and other products can be parts of the system. None of them owns the core model of your institution.
Not a compliance checkbox
It is an operating layer for your institution. It turns your knowledge, policies, requirements, authority, capabilities, markets, software, evidence, and outcomes into typed objects. You can run and audit these objects.

The claim

The size of a model does not decide which organizations get value from AI. The organizations that get value can defend their numbers to an auditor. They can replace a vendor without a rebuild, and move a runtime without a rewrite. They can trace each artifact to an intent that they own.

Sovereign Source AI is the architecture for these organizations. It is open, you can move it, and you can audit it.
